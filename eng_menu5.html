Web analytics with GoatCounter: This website uses the open-source web analytics service GoatCounter, operated by Martin Tournoij (Ireland), to statistically evaluate page usage and optimize our offering.

Scope and operation of data processing:
GoatCounter operates without cookies and stores no information (such as in localStorage) on your device. No persistent user profiles are created, and visitors are not tracked across multiple days or websites. When a page is loaded, technical information such as the requested URL, referrer (previously visited page), browser type, operating system, screen size, and approximate country of origin is recorded. To distinguish multiple page views within a single session (up to 8 hours), GoatCounter briefly generates a random hash in memory from your IP address, user agent, and page name. Your IP address is never stored in plain text or permanently in a database. Ultimately, we only receive anonymized, aggregated statistics.
